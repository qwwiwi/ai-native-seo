# Как установить Claude Code в 2026: Windows, Mac, Linux пошагово

Установить Claude Code проще, чем кажется на старте: на большинстве систем это одна команда в терминале. Сложности обычно не в самой установке, а в мелочах вокруг неё – какой способ выбрать на Windows, что делать с доступом к моделям и почему после запуска открывается браузер. Разберём весь путь по шагам для всех трёх платформ.

Если совсем коротко: **на macOS и Linux Claude Code ставится одной официальной командой установки, на Windows – нативной командой в PowerShell или той же командой внутри WSL, а после установки вы запускаете его командой `claude` и входите через браузер.**

Ниже – детали для каждой системы, заметка про доступ к Claude, первый запуск и таблица частых ошибок.

## Что нужно перед установкой

Перед командой установки стоит закрыть два момента, иначе застрянете на середине.

Первое – доступ к моделям Claude. Сам инструмент бесплатный, но работать без доступа к моделям он не будет. Claude Code требует платного плана: подойдёт подписка Claude (Pro, Max, а также командные и корпоративные планы) либо аккаунт Anthropic Console с API-ключом. Бесплатный план Claude.ai доступ к Claude Code не даёт. Если ещё не решили, какой путь выбрать, разберитесь с этим заранее в гайде про [подписку и API-ключ для Claude Code](/guides/claude-code-api/) – это сэкономит время на шаге входа.

Второе – Node.js. Официальный установщик ставит готовую сборку и в большинстве случаев тянет всё нужное сам, отдельная установка Node.js обычно не требуется. Но если вы предпочитаете ставить Claude Code через менеджер пакетов npm, тогда Node.js нужен заранее. Для базового пути из этого гайда хватит официальной команды установки.

И общее для всех систем – терминал. Это текстовое окно, куда вы вводите команды. На Mac это приложение «Терминал», на Linux – любой терминал вашего окружения, на Windows – окно WSL, к которому мы вернёмся ниже. Бояться его не нужно: на установку уходит несколько строк.

## Шаг 1: Установка на macOS

На macOS используется официальный установщик – одна команда в Терминале.

Откройте приложение «Терминал» (поиск Spotlight по слову «Терминал») и вставьте команду:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Команда скачивает официальный установочный скрипт и сразу его запускает. Дождитесь окончания – в конце вы увидите сообщение, что Claude Code установлен. После этого можно переходить к [первому запуску](#шаг-4-первый-запуск-и-вход-через-браузер).

Если в процессе появляется ошибка про права доступа или «command not found», загляните в таблицу [частых ошибок](#частые-ошибки) ниже – там разобраны типовые случаи.

## Шаг 2: Установка на Linux

На Linux путь точно такой же, как на macOS – тот же официальный установщик и та же команда.

Откройте терминал вашего дистрибутива и выполните:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Скрипт определит вашу систему, скачает нужную сборку и установит Claude Code. По завершении в терминале появится подтверждение установки. Дальше – к разделу про [первый запуск](#шаг-4-первый-запуск-и-вход-через-браузер).

Утилита `curl` есть в большинстве дистрибутивов из коробки. Если терминал отвечает, что команда `curl` не найдена, установите её через пакетный менеджер вашей системы (например, через apt или dnf) и повторите.

## Шаг 3: Установка на Windows

На Windows есть два рабочих пути: нативная установка через PowerShell и установка внутри WSL. Оба официальные – выбирайте по своему окружению.

**Путь 1: нативно через PowerShell (быстрее всего).** Откройте PowerShell и выполните:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Команда скачивает официальный установщик для Windows и ставит Claude Code. После этого запускаете его командой `claude` прямо в PowerShell или командной строке.

**Путь 2: через WSL.** Подходит, если ваши проекты и инструменты Linux-ориентированы или нужна изоляция. WSL (Windows Subsystem for Linux) – встроенная в Windows подсистема, которая запускает полноценное окружение Linux прямо внутри Windows, без отдельной виртуальной машины.

1. Включите WSL. Откройте PowerShell от имени администратора, выполните `wsl --install` и перезагрузите компьютер, если система попросит. Появится терминал Linux (по умолчанию – Ubuntu).
2. Откройте терминал WSL – запустите установленный дистрибутив (например, Ubuntu) из меню «Пуск».
3. Выполните ту же команду, что и на Linux:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

В этом случае вы работаете в Linux-окружении, и команду `claude` запускаете внутри окна WSL. Не уверены, что выбрать – начните с нативного пути через PowerShell, он проще.

Если хотите сразу собрать вокруг этого рабочую базу настроек и первых команд, удобно опереться на [стартовый набор для Claude Code](/guides/claude-code-starter-kit/) – он ведёт от установки до первых задач единым маршрутом.

## Шаг 4: Первый запуск и вход через браузер

Установка прошла – осталось запустить инструмент и войти в аккаунт. Шаги одинаковы на всех платформах (на Windows – внутри окна WSL).

1. Перейдите в папку с вашим проектом. В терминале это делается командой перехода в каталог – откройте ту папку, с файлами которой хотите работать. Claude Code привязывается к текущей папке, поэтому запускать его лучше внутри проекта, а не в произвольном месте.
2. Запустите Claude Code командой:

```bash
claude
```

3. Войдите в аккаунт. При первом запуске Claude Code предложит авторизоваться и откроет вход через браузер. Авторизуйтесь под тем аккаунтом, где у вас есть доступ к Claude (подписка или API-ключ), и подтвердите вход. После этого вернитесь в терминал – Claude Code будет готов к работе.

Дальше вы просто пишете задачу обычными словами прямо в терминале, и агент предлагает, что сделать. Если хотите освоить именно общение с агентом, а не только установку, помогает практика в формате [вайб-кодинга](/guides/vaib-koding/) – когда вы ставите задачи словами и ведёте работу диалогом.

## Частые ошибки

Большинство проблем при установке – типовые. Вот что встречается чаще всего и как реагировать.

| Симптом | Вероятная причина | Что делать |
|---|---|---|
| `command not found: claude` после установки | Путь к Claude Code не подхватился терминалом | Закройте и откройте терминал заново; если не помогло – перезайдите в систему, чтобы окружение обновилось |
| `curl: command not found` | В системе нет утилиты curl | Установите curl через пакетный менеджер (apt, dnf, brew) и повторите команду установки |
| Ошибка прав доступа во время установки | Скрипту не хватает прав на запись | Запускайте команду от своего пользователя в домашней папке; не используйте чужие системные каталоги |
| После `claude` просит оплату или доступ | Нет активной подписки или API-ключа | Claude Code требует платного доступа – оформите подписку Claude или ключ Anthropic Console |
| На Windows `claude` не находится после установки | Терминал не подхватил путь, или ставили в WSL, а запускаете вне него | Перезапустите терминал; при установке через WSL все команды, включая `claude`, выполняйте внутри окна WSL |
| Браузер не открылся для входа | Терминал без графической среды или блокировка | Откройте показанную в терминале ссылку для входа вручную в браузере |

Если ошибка не из таблицы – скопируйте текст сообщения целиком, обычно в нём прямо указана причина.

## FAQ

### Как установить Claude Code на Windows?

На Windows два пути. Нативно: откройте PowerShell и выполните `irm https://claude.ai/install.ps1 | iex` – дальше запускаете `claude` прямо в PowerShell. Или через WSL (Windows Subsystem for Linux): включите WSL командой `wsl --install`, откройте его терминал (Ubuntu) и выполните ту же команду, что на Linux: `curl -fsSL https://claude.ai/install.sh | bash`, запуская `claude` внутри окна WSL. Не уверены – начните с нативного пути.

### Нужен ли платный доступ к Claude?

Да. Сам Claude Code устанавливается бесплатно, но для работы ему нужен доступ к моделям Claude, а это платный план. Подойдёт подписка Claude (Pro, Max, командные и корпоративные планы) либо аккаунт Anthropic Console с API-ключом. Бесплатный план Claude.ai доступ к Claude Code не даёт.

### Можно ли установить Claude Code без программирования?

Да, для самой установки навыки программирования не нужны – достаточно вставить одну команду в терминал и дождаться окончания. Сложнее обычно не установить, а научиться ставить задачи агенту словами, но и это вопрос практики, а не знания языков программирования. Терминал здесь – просто окно для пары команд, а не то, что нужно учить наизусть.

### Нужно ли отдельно ставить Node.js?

Для базового пути из этого гайда – обычно нет. Официальный установщик ставит готовую сборку и тянет нужное сам. Node.js понадобится отдельно, если вы предпочитаете устанавливать Claude Code через менеджер пакетов npm. Для большинства новичков проще начать с официальной команды установки.

### На какие системы можно установить Claude Code?

На macOS, Linux и Windows. На macOS и Linux используется официальный установщик одной командой. На Windows есть нативный установщик для PowerShell и путь через WSL, который даёт окружение Linux прямо в Windows. Способ запуска и вход через браузер после установки на всех системах одинаковы.
