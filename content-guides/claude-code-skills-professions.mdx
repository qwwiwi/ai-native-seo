# Скиллы Claude Code под профессии 2026: не только для кода

Claude Code из коробки заточен под работу с кодом. Но скиллы снимают это ограничение: ставишь скилл под свою профессию – и агент действует как специалист в ней, по методике, а не общими словами. Под маркетинг, дизайн, контент и продукт уже есть готовые наборы; под более узкие роли скилл часто проще собрать самому.

Прямой ответ: ищи скилл по своей профессии или задаче командой `npx skills find <запрос>` в каталоге skills.sh – там собраны скиллы далеко за пределами разработки.

## Скиллы не только для разработчиков

Скилл – это `SKILL.md`: упакованная методика, которую Claude загружает в контекст. Методика может быть любой – не только про код. Поэтому в открытом каталоге [skills.sh](https://skills.sh) (от Vercel, поверх стандарта Agent Skills от Anthropic) лежат скиллы под маркетинг, дизайн, контент и продукт, а под более узкие роли методику можно найти в профильных репозиториях на GitHub или написать свою.

Главное – не уметь программировать, а ясно сформулировать задачу. Скилл превращает Claude Code из «универсального помощника» в специалиста под конкретную роль.

## Под какие профессии есть готовые скиллы

В каталоге skills.sh уже лежат рабочие скиллы под:

| Профессия | Что закрывает скилл |
|---|---|
| Маркетолог | копирайтинг, контент-план, реклама, SEO-аудит |
| Дизайнер | UI-ревью, дизайн-система, проверка макета на «AI-халтуру» |
| Контент / SMM | сценарии, карусели, адаптация под каналы |
| Продакт | спецификации (PRD), разбор фич, планы |

Под более узкие роли – аналитик, рекрутер, юрист, консультант – на skills.sh готового часто нет. Но это не тупик: такие методики либо лежат в профильных репозиториях на GitHub, либо собираются под себя за несколько минут (см. ниже «Чего нет готового – собери свой»). Скилл – это просто файл с методикой, и под узкую профессию его обычно проще написать, чем искать.

## Как найти скилл под свою профессию

Самый быстрый путь – поиск из терминала по профессии или задаче:

```bash
npx skills find <профессия или задача>
```

Например, `npx skills find marketing` или `npx skills find design`. Команда покажет подходящие скиллы с автором и числом установок – по `marketing`, например, найдётся популярный `coreyhaines31/marketingskills`. Число установок помогает оценить популярность, но всё равно открой `SKILL.md` и посмотри, по какой методике скилл работает.

Установка – одной командой, под Claude Code:

```bash
npx skills add <автор/репо> -a claude-code
```

Как именно ставить, куда попадает скилл и как проверить, что Claude его подхватил – пошагово в гайде [Как установить скилл в Claude Code](/guides/claude-code-skills-install/), а где искать любые скиллы – в [Скиллы для Claude Code](/guides/claude-code-skills/).

## Чего нет готового – собери свой

Если под твою узкую нишу готового скилла нет – это нормально. Скилл – это просто `SKILL.md` с методикой. Опиши в нём, как работает специалист в твоей области (шаги, чек-листы, правила), и Claude будет следовать ему так же, как покупному скиллу. По сути ты упаковываешь свою экспертизу в файл, который агент применяет за тебя.

Начни с настройки Claude Code с нуля – [Starter Kit](/guides/claude-code-starter-kit/) проведёт по базе.

## FAQ

### Есть ли скиллы Claude Code для не-программистов?
Да. Скиллы – это методики, а не код. В каталоге skills.sh есть готовые наборы под массовые роли – маркетинг, дизайн, контент, продукт; под узкие (аналитик, HR, юрист) методику берут из профильных репозиториев на GitHub или пишут свой `SKILL.md`. Программировать, чтобы пользоваться, не нужно.

### Как найти скилл под свою профессию?
Командой `npx skills find <профессия или задача>` (например, `marketing`, `design`) в каталоге skills.sh. Под более узкие роли (юрист, рекрутер, аналитик) готового там может не быть – тогда смотри профильные репозитории на GitHub или собери свой скилл. Число установок помогает оценить популярность; читай `SKILL.md` перед установкой.

### Что делать, если под мою нишу скилла нет?
Собрать свой: скилл – это файл `SKILL.md` с описанием методики. Опиши, как работает специалист в твоей области (шаги, правила, чек-листы), и Claude будет ему следовать.

### Нужно ли уметь программировать, чтобы пользоваться скиллами?
Нет. Главный навык – ясно поставить задачу и проверить результат, а не писать код. Скилл закрывает методику за тебя.
