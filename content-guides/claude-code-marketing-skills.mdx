# Маркетинговые скиллы для Claude Code 2026: как активировать

Claude Code из коробки – универсальный кодер. Но кодер не пишет продающие тексты, не считает воронку и не аудитит сайт по SEO. Маркетинговый скилл закрывает этот разрыв: ставишь его – и агент начинает работать как маркетолог по проверенной методике, а не как чат, который «что-то посоветует».

Прямой ответ: маркетинговые скиллы берут в каталоге skills.sh, ставят одной командой `npx skills add`, активируются сами – Claude подхватывает скилл по контексту задачи.

## Что такое маркетинговый скилл

Скилл – это `SKILL.md`: подробная инструкция, которую Claude загружает в контекст и которой следует. Маркетинговый скилл – тот же формат, но с экспертизой в конкретной маркетинговой задаче: копирайтинг по формулам, SEO-аудит по чек-листу, разбор воронки, генерация контент-плана.

Один скилл меняет поведение агента сильнее, чем 50 строк промпта. Ставишь скилл копирайтинга – Claude пишет тексты по проверенным формулам (например, AIDA, PAS), а не «как нейросеть».

Сам формат Agent Skills – открытый стандарт от Anthropic, поэтому скиллы работают в Claude Code без плагинов. А skills.sh и CLI `npx skills` – это популярный каталог и установщик от Vercel поверх этого стандарта (не сам формат и не реестр Anthropic).

## Какие маркетинговые скиллы есть

Под маркетинг в каталоге собираются скиллы по направлениям:

| Направление | Что делает скилл |
|---|---|
| Копирайтинг | продающие тексты, заголовки, офферы по формулам (AIDA, PAS, 4U) |
| SEO | аудит страницы по 50+ пунктам, подбор запросов, мета-теги |
| Контент | контент-план, рубрикатор, адаптация поста под каналы |
| Реклама | креативы, тексты объявлений, A/B-варианты |
| Соцсети | сценарии рилсов, карусели, прогрев |
| Лендинги | структура, секции, призывы под продукт |

Точные названия и авторы меняются – ищи по задаче в каталоге, не по памяти.

## Шаг 1: найди скилл в каталоге
Открой [skills.sh](https://skills.sh) или ищи прямо из терминала: `npx skills find marketing` (или `copywriting`, `seo`). Каталог покажет подходящие скиллы с автором и числом установок.

## Шаг 2: поставь одной командой
Установка: `npx skills add <автор/репо> -a claude-code`. Скилл ставится в окружение Claude Code (папка `.claude/skills/`), и Claude Code сразу его видит.

## Шаг 3: проверь, что скилл на месте
Проверь, что скилл появился в папке `.claude/skills/`, и дай задачу из его зоны («напиши оффер для лендинга») – если ответ идёт по методике скилла, а не общими словами, скилл активен.

## Как активировать и не промахнуться

Отдельной кнопки «включить» нет – Claude активирует нужный скилл сам, по контексту задачи (если скилл поддерживает ручной вызов, его можно запустить slash-командой с его именем). Чтобы он точно подхватил маркетинговый скилл:

- Формулируй задачу в терминах маркетинга («напиши продающий текст», «сделай SEO-аудит этой страницы») – так агент понимает, какой скилл применить.
- Держи узкий набор скиллов под свои задачи, а не сто подряд – меньше путаницы, точнее срабатывание.
- Один скилл за раз при проверке: поставил – протестировал на реальной задаче – оставил или снёс.

:::tip Готовая методика под задачу
Маркетинговый скилл – это упакованная методика (формулы, чек-листы), которую агент применяет за тебя. Рутину старта снимает, но результат всё равно проверяешь сам.
:::

## FAQ

### Как активировать навыки Claude для маркетолога?
Отдельной активации не нужно – ставишь маркетинговый скилл командой `npx skills add`, и Claude Code применяет его сам, когда задача относится к маркетингу. Достаточно сформулировать запрос в терминах маркетинга.

### Где взять маркетинговые скиллы для Claude?
В каталоге skills.sh (от Vercel) – по поиску `marketing`, `copywriting`, `seo`. Многие доступны бесплатно и ставятся одной командой; условия смотри на странице скилла.

### Как установить маркетинговый скилл в Claude Code?
Командой `npx skills add <автор/репо> -a claude-code` из терминала в папке проекта. После установки Claude Code сразу видит скилл.

### Чем маркетинговый скилл лучше обычного промпта?
Скилл – это полная методика (формулы, чек-листы, шаги), которую Claude держит в контексте, а не разовая подсказка. Один скилл меняет поведение агента сильнее, чем длинный промпт, и работает стабильно от задачи к задаче.
