# Codex 2026: как зайти и когда он сильнее Claude Code

Codex – ответ OpenAI на Claude Code. Тот же класс инструмента: агент живёт в терминале, читает весь проект, правит файлы, запускает команды и доводит задачу до результата. Но характер у него другой, и на части задач он выигрывает.

Разберём, что такое Codex сегодня, как в него войти, и – главное – когда брать Codex, а когда Claude Code.

## Что такое Codex

Codex – это не одна программа, а семейство. Есть **Codex CLI** – терминальный агент с открытым кодом (репозиторий `github.com/openai/codex`), это основной инструмент. Есть **Codex Desktop** – десктоп-приложение, запускается командой `codex app`. И есть **Codex Cloud** – облачный агент на `chatgpt.com/codex`: берёт GitHub-задачи и пул-реквесты, работает асинхронно без вашего терминала.

Под капотом по умолчанию работает gpt-5.5 – сильнейшая на сегодня агентная модель OpenAI для кода. Есть и другие: gpt-5.4, лёгкая gpt-5.4-mini для простых задач и субагентов, превью gpt-5.3-codex-spark.

## Установка и вход

:::kinescope 56f3ef8d-b5de-46dc-8a79-79e7f9da6815
Почему с Codex работают только через подписку, а не по API-ключу: $200 подписки ≈ $12–14k в токенах по API. Фрагмент эфира про Codex.
:::

Поставить CLI – одной командой: `curl -fsSL https://developers.openai.com/codex/install.sh | bash`. Либо через npm (`npm install -g @openai/codex`), либо через Homebrew (`brew install openai/codex/codex`) – что привычнее.

Вход – через вашу подписку ChatGPT (Plus, Pro, Business): команда `codex login` откроет браузер с OAuth. Для сервера без браузера есть вход по коду – `codex login --device-auth`. Технически можно войти и по сырому API-ключу (для CI и скриптов), но для обычной работы это не нужно: **подписка выгоднее ключа в разы**, и это та же логика, что и в Claude Code. У Claude Code, кстати, есть и [бесплатные способы начать](/guides/free-claude-code/) – если хочется сначала пощупать второго агента без оплаты подписки.

Модель задаётся флагом `codex -m gpt-5.5` или в файле `~/.codex/config.toml`. Для тяжёлых задач держите gpt-5.5, а на простом и на субагентах – gpt-5.4-mini.

## Codex против Claude Code

Оба – сильные агенты, но с разным характером. Коротко: Codex точнее исполняет, Claude Code лучше думает. Если хочется увидеть, где оба стоят среди остальных инструментов, посмотрите [тир-лист AI-инструментов 2026](/guides/ai-tools-tier-list/) – там расклад по всему рынку, а не только эта пара.

| Брать Codex, когда | Брать Claude Code, когда |
|--------------------|--------------------------|
| Нужно точное исполнение по спеке | Нужны ресёрч, архитектура, план |
| Рефакторинг, тесты, работа в терминале | Расплывчатая задача «сделай фичу» |
| Строгое следование правилам (AGENTS.md) | Навигация по большому запутанному коду |
| Цена и стабильность критичны | Зрелая экосистема MCP, enterprise-доступ |
| Неинтерактивная автоматизация, пайплайны | Долгие автономные сборки с нуля |

Сильные стороны Codex стоит назвать отдельно. Он строго следует инструкциям: уважает правила из файла `AGENTS.md` и не «поддакивает» – грызёт задачу по спеке, меньше уходит в сторону. У него явная песочница с уровнями доступа (`read-only`, `workspace-write`, `danger-full-access`) – контроль над тем, что агенту позволено. И есть неинтерактивный режим `codex exec` с потоковым JSONL-выводом и валидацией схемы – его удобно встраивать в оркестрацию и CI.

Claude Code, в свою очередь, сильнее в архитектуре, планировании и работе с расплывчатыми задачами, где надо догадаться о намерении.

Поэтому лучшая связка – не «или-или», а гибрид: Claude Code пишет план и архитектуру, Codex реализует и прогоняет тесты, Claude Code ревьюит результат. Две разные модели ловят разные классы ошибок – это и есть **двойное ревью** из видео выше.

## Superpowers: дисциплина для агента

:::kinescope 42972ef9-b663-46be-92c3-326e37d6b9f5
Установка Superpowers через плагины-маркетплейс: где лежат навыки и как их подключить. Фрагмент эфира про Codex.
:::

Superpowers (репозиторий `github.com/obra/superpowers`) – методология и набор навыков, которые навязывают агенту инженерную дисциплину: уточни задачу → план → тесты сначала → ревью → финиш. Вместо «накидал кода» агент идёт по проверяемому процессу.

Фреймворк создан в первую очередь под Claude Code – там интеграция самая зрелая (через систему хуков и навыков). С Codex он тоже работает, но через плагины или правила в `AGENTS.md`, и потребует чуть больше ручной настройки.

## Как делегировать задачи Codex

Codex удобно подключать как исполнителя к другому агенту или скрипту. Путей два.

Первый – **Codex как MCP-сервер**: он отдаёт свои возможности любому родительскому агенту через stdio (команда `codex mcp-server`). Так Claude Code или ваш собственный оркестратор может передавать Codex точечную работу.

Второй – **неинтерактивный режим** для скриптов и CI, с машинно-читаемым выводом: например, `codex exec --json "напиши тесты для платёжного модуля"`, или с выходной схемой – `codex exec "извлеки метаданные проекта" --output-schema ./schema.json`. Результат забирается структурированно, без ручного копирования.

## Итог

Codex и Claude Code – не конкуренты «кто лучше вообще», а два инструмента под разные фазы. Claude Code – думать, планировать, разбираться в незнакомом. Codex – точно исполнять, рефакторить, гонять тесты и встраиваться в автоматизацию. Сильный сетап держит оба и переключается по задаче.

## FAQ

### Что такое Codex и чем он отличается от Claude Code?
Codex — ответ OpenAI на Claude Code: терминальный агент на GPT-5.5, который читает репозиторий, правит файлы и гоняет команды. Отличие — модель и сильные стороны на разных типах задач; в гайде честное сравнение по сценариям.

### Когда Codex сильнее Claude Code?
На части задач (особенно где силён GPT-5.5) Codex даёт лучший результат — гайд разбирает, где какой агент выигрывает и как использовать двойное ревью Codex + Claude.

### Как получить доступ к Codex?
Вход по подписке OpenAI; в гайде — как подключить и как делегировать Codex работу из терминала.

### Как зайти в Codex
Зайти в Codex – значит авторизоваться в Codex CLI под своим аккаунтом ChatGPT. Ставите CLI одной командой, запускаете вход – открывается браузер с логином через ChatGPT, после чего агент готов к работе. Если работаете на сервере без браузера – есть вход по коду устройства (device-auth).

### Codex работает по подписке ChatGPT
Да. Вход в Codex – это вход вашим аккаунтом ChatGPT, и Codex включён в планы Plus, Pro, Business, а также в бесплатный и корпоративные тарифы. Отдельной подписки на Codex не существует: платите за ChatGPT – Codex идёт в комплекте. Технически можно войти и по API-ключу, но для обычной работы подписка выгоднее.

### Сколько стоит войти в Codex
Отдельной платы за вход нет – Codex входит в вашу подписку ChatGPT. Пощупать можно на бесплатном тарифе; для регулярной работы берут Plus (около $20/мес), а для тяжёлой нагрузки – Pro (от $100/мес с кратно большими лимитами). «Цена входа» в Codex – это стоимость плана ChatGPT, а не отдельный счёт.

### Codex или Claude Code — что выбрать
Зависит от задачи, а не от того, кто «лучше вообще». Codex берут, когда нужно точное исполнение по спеке, рефакторинг, тесты и автоматизация; [Claude Code](/guides/chto-takoe-claude-code/) – когда нужны ресёрч, архитектура и работа с расплывчатой задачей. Сильный сетап держит оба и переключается по фазе – план и ревью на Claude Code, исполнение на Codex.
