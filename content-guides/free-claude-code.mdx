# Бесплатный Claude Code 2026: 3 рабочих способа

Claude Code – это в первую очередь клиент. Сам интерфейс, агентные циклы, работа с файлами – всё это не зависит от того, какая модель отвечает на запросы. А значит, его можно направить на бесплатные или локальные модели и сохранить тот же рабочий процесс за 0 рублей.

Ниже – три способа сделать это, от самого удобного до полностью локального. С реальными командами и честными оговорками, где качество просядет.

## Как это вообще работает

Claude Code читает две переменные окружения и по ним решает, куда слать запросы:

- `ANTHROPIC_BASE_URL` – адрес, куда уходит трафик.
- `ANTHROPIC_AUTH_TOKEN` – токен, который уходит в заголовке `Authorization`.

Дальше два варианта. Либо вы указываете провайдера, который уже понимает формат Anthropic напрямую (OpenRouter, Ollama). Либо ставите небольшой локальный прокси, который переводит формат Anthropic в формат других провайдеров (NVIDIA NIM и прочие). Второе и делают готовые инструменты вроде free-claude-code.

## Способ 1: free-claude-code (всё в одном)

`free-claude-code` – прокси, который уводит трафик Claude Code на любого из множества провайдеров и даёт удобную админку. Это самый простой путь, если хочется переключаться между провайдерами в пару кликов.

Установка – одна команда. Она доустановит сам Claude Code, если его нет, и поставит прокси:

```bash
curl -fsSL "https://github.com/Alishahryar1/free-claude-code/blob/main/scripts/install.sh?raw=1" | sh
```

Запуск прокси:

```bash
fcc-server
```

В терминале появится адрес админки – обычно `http://127.0.0.1:8082/admin` (доступна только локально). Откройте её, выберите провайдера (NVIDIA NIM, OpenRouter, Ollama и другие) и вставьте ключ. После этого запускаете Claude Code через прокси:

```bash
fcc-claude
```

:::tip Совет
Прокси умеет роутить по моделям: Opus, Sonnet и Haiku можно отправлять к разным провайдерам, а в нативном меню `/model` появятся модели прокси. Удобно держать дорогую модель на платном ключе, а массовую работу гнать через бесплатную.
:::

## Способ 2: напрямую через OpenRouter

Если не хочется ставить прокси, Claude Code можно направить прямо на OpenRouter – он понимает формат Anthropic. Зарегистрируйтесь на openrouter.ai, создайте ключ (`sk-or-v1-...`) и задайте переменные:

```bash
export OPENROUTER_API_KEY="ваш-ключ"
export ANTHROPIC_BASE_URL="https://openrouter.ai/api/v1"
export ANTHROPIC_AUTH_TOKEN="$OPENROUTER_API_KEY"
export ANTHROPIC_API_KEY=""
claude --model "deepseek/deepseek-r1:free"
```

Переменную `ANTHROPIC_API_KEY` нужно явно оставить пустой. Если вы уже были залогинены в Anthropic – сначала выполните `/logout` внутри Claude Code и перезапустите его.

## Способ 3: локально через Ollama

Полностью локальный вариант, без ключей и без интернета. Ставите Ollama, скачиваете модель и запускаете Claude Code на ней:

```bash
ollama launch claude
# или вручную:
ANTHROPIC_AUTH_TOKEN=ollama ANTHROPIC_BASE_URL=http://localhost:11434 claude --model qwen3-coder
```

Токен здесь – формальность (`ollama`), реальная цена – ваше железо и видеопамять.

## Какие модели реально бесплатны

На OpenRouter у бесплатных моделей суффикс `:free`. Проверенные рабочие варианты:

| Модель | Слаг на OpenRouter | Бесплатно |
|--------|--------------------|-----------|
| DeepSeek R1 | `deepseek/deepseek-r1:free` | да |
| Kimi K2 | `moonshotai/kimi-k2:free` | да |
| GLM 4.5 Air | `z-ai/glm-4.5-air:free` | да |
| GLM 4.6 | `z-ai/glm-4.6` | нет, платная |

Конкретные `:free`-модели меняются – проверь актуальный список на `openrouter.ai/models?free=true`.

:::warning Важно
GLM 4.6 – платная, не путайте. Бесплатная версия GLM – это `z-ai/glm-4.5-air:free`. Берите модель с суффиксом `:free`, иначе спишутся деньги.
:::

## Где взять бесплатный ключ

- OpenRouter – регистрация на openrouter.ai, ключ `sk-or-v1-...`, дальше любые модели с суффиксом `:free`.
- NVIDIA NIM – бесплатный тариф, ключ вида `nvapi-...`. Формат у него OpenAI, не Anthropic, поэтому нужен прокси (способ 1).
- Ollama – ключ не нужен вообще, всё крутится у вас локально.

## Чего ждать и где подвохи

Бесплатно – не значит без компромиссов. Что важно знать заранее:

- Claude Code заточен под модели Anthropic. На сторонних моделях вызовы инструментов работают менее стабильно – агентные сценарии чаще требуют повторов и присмотра.

- Если шлюз ругается на экспериментальные заголовки – помогает переменная `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1`.

- У бесплатных моделей есть лимиты по частоте запросов: на OpenRouter и NVIDIA NIM они невысокие и по сообщениям сообщества плавают. Если упираетесь в потолок и на платной подписке Anthropic, разобраться помогает гайд про [лимиты Claude Code и как в них не упираться](/guides/claude-code-limits/). Для спокойной работы это терпимо, для тяжёлых параллельных сессий – нет.

- Качество бесплатных моделей пригодно для кода, но им не хватает «выносливости» Claude на длинных автономных задачах. Ждите больше ручного контроля.

## Итог

Claude Code не привязан к одной модели. Для проб, учёбы и нетяжёлых задач его реально гонять бесплатно: проще всего через `free-claude-code`, гибче – напрямую через OpenRouter, приватнее – локально на Ollama. Платную модель Anthropic держите для сложного, бесплатную – для всего остального. Да — Claude Code читает переменные ANTHROPIC_BASE_URL и ANTHROPIC_AUTH_TOKEN, поэтому его трафик можно увести на бесплатного провайдера. В гайде три способа с реальными командами.

### Как запустить Claude Code на бесплатных моделях?
