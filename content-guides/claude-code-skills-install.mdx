# Как установить скилл в Claude Code 2026: пошагово

Скилл для Claude Code ставится одной командой `npx skills add`. Сложного ничего нет, но новички спотыкаются на двух вещах: не понимают, куда скилл устанавливается, и не умеют проверить, что он работает. Разберём по шагам.

Прямой ответ: открой терминал в папке проекта, выполни `npx skills add <автор/репо> -a claude-code` – скилл появится для Claude в `.claude/skills/` (обычно как симлинк на `.agents/skills/`), и Claude Code подхватит его сам.

## Что нужно перед установкой

- **Claude Code** – с любым доступом к Claude (подписка или API-ключ). Сами скиллы Claude Code отдельного тарифа не требуют; Pro/Max нужны для скиллов в десктоп- и веб-приложениях Claude, а не в Claude Code.
- **Терминал** – Mac, Linux или Windows через WSL.
- **Node.js** – нужен для `npx` (команда установки идёт через него).

Проверь Node одной командой: `node -v`. Если версия вывелась – всё готово. Если «command not found» – поставь Node с nodejs.org, потом вернись.

## Шаг 1: найди скилл

Скиллы лежат в каталоге [skills.sh](https://skills.sh) (от Vercel, поверх открытого стандарта Agent Skills от Anthropic). Найди нужный по задаче – на сайте или из терминала: `npx skills find <запрос>` (например, `copywriting`, `seo`, `debugging`). Команда покажет подходящие скиллы с автором и числом установок – по нему удобно оценить популярность, но всё равно читай `SKILL.md` перед установкой.

Запиши путь скилла в формате `<автор/репо>` – он понадобится в следующем шаге.

## Шаг 2: установи командой

В терминале, находясь в папке своего проекта, выполни:

```bash
npx skills add <автор/репо> -a claude-code
```

Флаг `-a claude-code` говорит, что ставим скилл именно под Claude Code. Скилл скачается; Claude Code видит его через `.claude/skills/` (детали пути – в разделе «Куда устанавливается» ниже). Установка занимает секунды.

## Шаг 3: проверь, что скилл встал

Проверка в два касания:

- Загляни в папку `.claude/skills/` в проекте – там должна появиться папка скилла с файлом `SKILL.md`.
- Дай Claude Code задачу из зоны скилла («напиши оффер для лендинга» для копирайтинг-скилла). Если ответ идёт по методике скилла, а не общими словами – скилл активен.

Отдельной кнопки «включить» нет: Claude сам подхватывает нужный скилл по контексту задачи.

## Куда устанавливается скилл

Claude Code читает скиллы из папки `.claude/skills/` проекта. Нюанс установщика: `npx skills add` кладёт реальные файлы в `.agents/skills/`, а в `.claude/skills/` создаёт симлинк на них. Обычно это прозрачно – Claude видит скилл. Но симлинк иногда не создаётся (известный баг установщика) – тогда скилл лежит только в `.agents/skills/`, и Claude его «не видит».

Если столкнулся – три выхода: проверь обе папки (`.claude/skills/` и `.agents/skills/`); поставь с флагом `--copy` (положит реальные файлы прямо в `.claude/skills/`, без симлинка); или поставь глобально, под все проекты, с `-g`:

```bash
npx skills add <автор/репо> -a claude-code -g
```

Глобальный скилл ляжет в `~/.claude/skills/` (на уровень пользователя) и будет доступен везде. Без `-g` – только в текущий проект.

## Частые ошибки

| Проблема | В чём дело и что сделать |
|---|---|
| `npx: command not found` | Не установлен Node.js. Поставь с nodejs.org, проверь `node -v`. |
| Скилл встал, но Claude его «не видит» | Чаще всего скилл лёг в `.agents/skills/`, а симлинк в `.claude/skills/` не создался (баг установщика). Проверь обе папки; переставь с `--copy` или `-g`. И убедись, что ставил с флагом `-a claude-code`. |
| Поставил много скиллов сразу – путаница | Ставь по одному под задачу и проверяй. Узкий набор срабатывает точнее, чем сто скиллов вперемешку. |
| Не уверен, какой скилл взять | Смотри число установок в `npx skills find` и читай `SKILL.md` перед установкой. |

## FAQ

### Как скачать скилл для Claude Code?
Командой `npx skills add <автор/репо> -a claude-code` из терминала в папке проекта. Скилл скачивается из каталога skills.sh, и Claude Code видит его через `.claude/skills/` (детали пути – в разделе «Куда устанавливается»).

### Куда устанавливается скилл в Claude Code?
Claude читает скиллы из `.claude/skills/` проекта; установщик кладёт реальные файлы в `.agents/skills/` и делает туда симлинк (с флагом `--copy` – файлы прямо в `.claude/skills/`, без симлинка). С `-g` – глобально в `~/.claude/skills/`, под все проекты.

### Как проверить, что скилл работает в Claude Code?
Загляни в `.claude/skills/` – там должна быть папка скилла, и дай Claude задачу из его зоны: если ответ идёт по методике скилла, он активен. Отдельной кнопки включения нет – Claude подхватывает скилл по контексту.

### Нужна ли подписка Pro или Max для скиллов в Claude Code?
Отдельной подписки именно под скиллы не нужно – они работают на любом доступе к Claude Code (подписка Claude или API-ключ). Pro/Max требуются для скиллов в десктоп- и веб-приложениях Claude, а не в Claude Code.
