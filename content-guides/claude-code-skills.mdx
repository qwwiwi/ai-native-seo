# Скиллы для Claude Code 2026: сотни бесплатных навыков

Claude Code из коробки – универсальный кодер. Но кодер – не маркетолог, не дизайнер, не аналитик. Skills закрывают этот разрыв.

Один скилл меняет поведение агента сильнее, чем 50 строк промпта.

## Что такое Skills

Skill – это SKILL.md файл. Подробная инструкция, которую Claude загружает в контекст и следует ей. Не плагин, не расширение, не API – чистое процедурное знание.

Сам формат – открытый стандарт Agent Skills (спецификация `SKILL.md`: YAML-фронтматтер + progressive disclosure). Его создала и открыла в open source **Anthropic**. Именно поэтому формат подхватили десятки агентов. skills.sh и CLI `npx skills` – это уже каталог и инструмент установки от Vercel, не сам формат.

Установил скилл copywriting – Claude пишет продающие тексты по проверенным формулам. Установил seo-audit – проводит аудит сайта по 50+ пунктам. Установил systematic-debugging – дебажит по научной методологии вместо хаотичного перебора.

Сотни скиллов в открытом реестре. Бесплатно.

## Зачем нужны скиллы

:::tip Экспертиза без обучения
Установил скилл – агент сразу работает по лучшим практикам. Не надо писать промпт на 500 строк, объясняя как делать SEO-аудит.
:::

1. **Специализация.** Один Claude – и маркетолог, и дизайнер, и DevOps. Переключаешь скиллами, не агентами.

2. **Качество.** Скиллы пишут создатели технологий. Supabase написали скилл для работы с Postgres – кто знает свою базу лучше?

3. **Безопасность.** Каждый скилл проходит тройной аудит: Gen Agent Trust Hub, Socket, Snyk. Три независимых проверки безопасности.

4. **Универсальность.** Skills работают не только в Claude Code. Cursor, Windsurf, GitHub Copilot, Cline, Gemini CLI, OpenAI Codex – всего 20+ агентов поддерживают формат.

## Где искать скиллы

Главный реестр: **skills.sh**

:::note
skills.sh – открытый каталог от Vercel. Лидерборд, фильтры, аудит безопасности. Адрес: skills.sh
:::

Три раздела, которые нужно знать:

**Лидерборд** (главная страница) – топ скиллов по установкам. Здесь видно, что реально используют. На момент написания: find-skills – 1 млн установок, frontend-design от Anthropic – 291K (счётчики растут каждый день). Числа говорят сами за себя.

**Official** – скиллы от создателей технологий. Anthropic, Microsoft, Vercel, Supabase, Firebase, Sentry. Если official-скилл существует – ставь его, не community-версию.

**Audits** – результаты проверки безопасности. Три инструмента проверяют каждый скилл: Gen Agent Trust Hub (Safe/Unsafe), Socket (алерты), Snyk (уровень риска).

## Поиск через терминал

Не обязательно открывать сайт. Прямо в терминале:

```bash
npx skills find маркетинг
```

Или конкретнее:

```bash
npx skills find seo audit
npx skills find supabase database
npx skills find react design
```

## 5 правил поиска скиллов

Прежде чем ставить что попало – пять правил, которые сэкономят время и нервы.

### Правило 1: Official первым делом

Если скилл есть от создателя технологии – ставь его. Supabase написали скилл для Postgres? Бери supabase/agent-skills, не community-аналог. Anthropic сделали frontend-design? Не ищи замену.

Вкладка Official на skills.sh – первое место для поиска.

### Правило 2: Проверяй аудит

Вкладка Audits на skills.sh. Смотришь три столбца:

- Gen Agent Trust Hub: **Safe** – норма, Unsafe – не ставить
- Socket: **0 alerts** – норма, 1+ – изучить подробнее
- Snyk: **Low/Medium** – норма, High/Critical – не ставить

Формула: Safe + Low Risk + 0 alerts = можно ставить.

### Правило 3: Смотри установки

50K+ установок – скилл проверен сообществом. Тысячи разработчиков используют, баги находят быстро.

Меньше 1K – не значит плохой, но код стоит прочитать перед установкой.

### Правило 4: Читай SKILL.md

Каждый скилл – это GitHub-репозиторий. Открой, прочитай SKILL.md. Красные флаги:

- curl/wget на незнакомые внешние URL
- Закодированные строки (base64, hex)
- Инструкции игнорировать системный промпт
- Запись в системные директории

Увидел хоть одно – не ставить.

### Правило 5: Один за раз

Не ставь 20 скиллов сразу. Поставил – попробовал – работает – следующий. Так видишь эффект каждого и не раздуваешь контекст.

## Как установить

Одна команда:

```bash
npx skills add owner/repo
```

Пример:

```bash
npx skills add coreyhaines31/marketingskills
```

Скилл появится в `.claude/skills/` и Claude начнёт его использовать автоматически. Перезапуск не нужен.

Если скилл не встал или Claude его не подхватил – пошаговый разбор установки и проверки в гайде [как установить скилл в Claude Code](/guides/claude-code-skills-install/).

## Подарок: скилл для поиска скиллов

Мы сделали скилл, который автоматизирует весь процесс. Говоришь Claude «найди скилл для SEO» – он сам идёт на skills.sh, проверяет аудит, читает GitHub, смотрит код, и выдаёт вердикт: ставить или нет.

Три фазы работы:

1. **Поиск** – находит до 5 кандидатов на skills.sh и в Official
2. **Аудит** – проверяет безопасность (4 проверки на каждый скилл)
3. **Отчёт** – выдаёт рекомендацию с фактами

Установка:

```bash
npx skills add qwwiwi/skill-finder
```

:::tip После установки
Просто скажи Claude: «найди скилл для email-маркетинга» или «есть скилл для Stripe?» – skill-finder сделает всё сам.
:::

## FAQ

### Что такое skills для Claude Code?
Skills — это готовые наборы знаний и инструкций, которые расширяют Claude Code под конкретную задачу: маркетинг, дизайн, ресёрч, работу с данными. Ты ставишь скилл — и агент начинает действовать как специалист в этой области, без ручной настройки промптов.

### Как установить скилл в Claude Code?
Большинство скиллов ставятся одной командой через реестр skills.sh: `npx skills add <автор/репо>`. После установки Claude Code сам подхватывает скилл и применяет его, когда задача ему соответствует.

### Где найти бесплатные скиллы для Claude Code?
Основной каталог — реестр skills.sh (открытый, формат Anthropic Agent Skills) и GitHub. В гайде разобраны правила поиска рабочих скиллов и собран стартовый набор, чтобы не тонуть в сотнях вариантов.

### Сколько скиллов можно поставить в Claude Code?
Технического лимита нет — Claude подключает нужный скилл по контексту задачи, а не держит все сразу. Лучше собрать узкий набор под свои задачи, чем ставить всё подряд.
