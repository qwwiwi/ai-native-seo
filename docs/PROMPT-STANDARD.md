# Стандарт промптов в гайдах

Единый формат для промптов в гайдах blog.edgelab.space. Цель — чтобы читатель
(часто новичок, «с нуля») мог нажать «Скопировать» и сразу вставить рабочий
промпт в Claude / Hermes / Codex, ничего не вычищая руками.

Источник правды для авторов гайдов и агентов, пишущих контент. Применяется ко
**всем** новым и существующим гайдам в `content-guides/*.mdx`.

## Директива

Промпт — это callout-директива в MDX:

```
:::prompt Краткое название действия
<литеральный текст промпта — ровно то, что читатель вставит в агента>
:::
```

- Заголовок после `:::prompt ` — короткое действие в стиле гайда: «Активация TOV»,
  «Перенос памяти из ChatGPT», «Подбор скиллов под задачи». Без точки в конце.
- Закрывается строкой `:::`.

Как это рендерится: лайм-обведённый блок с надписью **ПРОМПТ · Название** и кнопкой
копирования (иконка буфера → галочка на 2 c). Кнопка копирует **всё тело блока**
(без строки-заголовка) — поэтому тело должно быть готовым к вставке.

## Золотое правило: блок = только промпт

Внутри `:::prompt` — **только литеральный текст промпта**. Любое объяснение
(зачем это, что произойдёт, ссылки на инструменты, контекст) выносится в обычный
абзац **до** блока. Кнопка копирует тело целиком, поэтому проза внутри блока
попадёт в буфер и сломает вставку.

**Нельзя** (объяснение вперемешку с промптом — копируется мусор):

```
:::prompt Автоматическая загрузка источников
Не обязательно добавлять всё вручную. Claude Code автоматизирует загрузку через API.

Установи скилл:
github.com/teng-lin/notebooklm-py (8K+ stars)

После установки Claude Code сам найдёт нужные видео и загрузит в ноутбук.
:::
```

**Правильно** (контекст — до блока, в блоке — чистый промпт):

```
Не обязательно добавлять источники вручную — Claude Code автоматизирует загрузку
через NotebookLM API (скилл `github.com/teng-lin/notebooklm-py`, 8K+ stars).

:::prompt Автоматическая загрузка источников
Установи скилл github.com/teng-lin/notebooklm-py. После установки найди видео по
теме «[моя тема]», отфильтруй и загрузи их в мой ноутбук NotebookLM.
:::
```

## Как писать сам промпт (для аудитории «с нуля»)

Промпт должен работать у новичка с первого раза. Структура — по порядку, не
обязательно все пункты:

1. **Контекст/роль** — что у читателя есть и кто агент в этой задаче.
   «Вот мои диалоги из ChatGPT (conversations.json)…»
2. **Задача** — одно ясное действие, повелительное наклонение: «Изучи…»,
   «Установи…», «Создай…».
3. **Формат вывода** — если важно, чем ответить: список, таблица, файл, шаги.

Правила:

- **Подставляемое — в квадратных скобках:** `[моя тема]`, `[блог / канал / соцсети]`,
  `[улучшить фокус / больше энергии]`. Так читатель сразу видит, что заменить.
- **Самодостаточность** — промпт не должен ссылаться на «как выше» или на соседний
  блок. Скопировал — работает.
- **Язык — тот, на котором инструмент работает лучше.** По умолчанию русский, на «ты»,
  как в гайдах. Но если инструмент сильнее на английском (напр. дизайн-промпты для
  Google Stitch) — промпт на английском, это норма.
- **Без markdown-разметки внутри** (`**жирный**`, `#`-заголовки) — это литеральный ввод.
  Для перечислений: тире `–` остаётся обычным текстом, дефис `-` отрендерится в
  `<ul>`-список. `#`-заголовок первого уровня парсер внутри блока выкидывает — промпту
  он и не нужен.
- **Длина** — ровно сколько нужно для результата, без воды. Лучше короткий рабочий
  промпт, чем абзац «магических слов».

## Чек-лист перед публикацией

- [ ] В блоке `:::prompt` — только то, что вставляют в агента (нет «зачем/что будет»).
- [ ] Заголовок — короткое действие, без точки.
- [ ] Подставляемые места — в `[квадратных скобках]`.
- [ ] Промпт самодостаточен (не ссылается на соседние блоки).
- [ ] «Скопировать» даёт чистый, готовый к вставке текст (проверить в превью).

## Файл-шаблоны и конфиги — НЕ через `:::prompt`

Если нужно показать **содержимое файла** (пример `context.md`, schema, конфиг) — то,
что читатель сохранит в файл, а не вставит в чат агента — используй обычный блок кода
(` ``` `), не `:::prompt`:

- блок кода копируется и отображается **дословно**, вместе с символами `#`, отступами и
  разметкой;
- внутри `:::prompt` парсер выкидывает `#`-заголовок первого уровня и сплющивает
  markdown — скопированный «файл» получится битым.

`:::prompt` — только для текста, который вставляют в агента. Файл — в ` ```lang `.

## Соседние директивы (для контекста)

Полный набор callout-директив в гайдах — чтобы не путать промпт с пояснением:

| Директива | Метка | Назначение |
|---|---|---|
| `:::prompt Название` | ПРОМПТ | Готовый к копированию промпт (этот стандарт) |
| `:::tip` | СОВЕТ | Полезный совет, лайфхак |
| `:::note` | ЗАМЕТКА | Уточнение, контекст |
| `:::warning` | ВНИМАНИЕ | Предупреждение, частая ошибка |
| `:::cta` | EDGELAB SPACE | Призыв вступить в сообщество |

Объяснение «зачем нужен промпт» — это `:::note` или обычный абзац, **не** часть
`:::prompt`.
