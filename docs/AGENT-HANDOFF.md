## КОНТЕКСТ
Это статический портал об AI-агентах **EdgeLab Space** (автор — Даши Ешиев, телеграм-канал «Записки AI-энтузиаста»). Все страницы — тонкие HTML-обёртки над одним React-движком. Стиль и компоненты централизованы. Твоя задача — забрать/перенести проект ПОЛНОСТЬЮ, со всеми десктопными и мобильными экранами и всеми элементами.

## АРХИТЕКТУРА (как это работает)
- Каждая страница задаёт `window.__GF_VIEW` (и иногда `window.__GF_CAT`), затем подключает `gf-app.jsx`. Mount-switch в конце `gf-app.jsx` по этим переменным рендерит нужный экран.
- Мобильная версия — одна оболочка `mobile.html`, экран выбирается ЯКОРЕМ: `mobile.html#home|#library|#claude|#hermes|#codex|#about`. Смена якоря перезагружает страницу (hashchange → reload).
- Единый стиль — `gf-styles.css`. Он НЕ редактируется напрямую: это сборка из блока `<style>` внутри `guides-funnel-explore.html`. Правишь стиль там → пересобираешь `gf-styles.css` из этого блока.
- Логика и тексты — `gf-app.jsx`. Любая правка там применяется ко всем страницам сразу.

## МОБАЙЛ-МАРШРУТЫ (одна оболочка mobile.html)
`mobile.html#home` · `#library` · `#claude` · `#hermes` · `#codex` · `#about`
Каждый — мобильная версия соответствующего экрана. Меню (бургер → шторка слева) ведёт ИМЕННО на эти мобильные маршруты, не на десктоп.

## КОМПОНЕНТЫ (в gf-app.jsx — ничего не пропусти)
- `Logo` — вордмарк edgelab·space (lime-квадрат 7px как разделитель).
- `Header` + `NavLinks` — меню: Главная · Все гайды · Claude Code · Hermes · Codex · О проекте + переключатель темы + «Вступить в сообщество».
- `PortalHead` + `MobileMenuPanel` — мобильная шапка: бургер открывает выезжающую слева шторку.
- `Home` — геро (слоты-баннеры) + секции «Статьи» и «Гайды».
- `Catalog` + `CommandPalette` — библиотека 500 гайдов: фасеты, уровни, пагинация, поиск ⌘K с живой фильтрацией (массив `ALL_GUIDES`).
- `GuidePage` + `Content` — статья из объекта `ARTICLES` (`claude`/`hermes`/`codex`): TL;DR, бейдж «протестировано», блок-схема (`FlowChart`), видео (`VideoEmbed`), чек-лист (`StepsGuide`), `Callout`, `Faq`, `Changelog`, `CtaDark`, `Sidebar`, `Toc`.
- `AboutPage` — о проекте + CTA + канал.
- `MobileArticle` / `MobileC` — статья в телефонной рамке; кнопка «Скопировать для агента» при скролле ниже 1500px.
- `MobileMenu` — демо мобильного меню (на холсте).
- `Footer` — брендинг, разделы, контакты, канал, реквизиты ИП.

## ДИЗАЙН-ТОКЕНЫ
- Светлая: `--bg:#FAF7F2 --text:#1c1c1f --muted:#6b7280`
- Тёмная: `--bg:#141416 --text:#f4f4f5 --muted:#9ca3af`
- Бренд: `--ink:#0A0A0A --lime:#D4FF00 --offwhite:#FBFBF8`
- Шрифты: Inter (текст), Inter Tight (заголовки), JetBrains Mono (эйбрау/цифры).
- lime-маркер (квадрат) — везде 7px с ink-обводкой.
- Темы переключаются классом `.theme-dark` (и `.gp.theme-dark` / `.phone.theme-dark`).

## ЭЛЕМЕНТЫ, КОТОРЫЕ ЛЕГКО ПРОПУСТИТЬ — ПРОВЕРЬ
- Поиск **⌘K** (командная палитра) на `library.html` и в мобайле.
- **Заполняемые слоты** (`<image-slot>`) в геро Главной, в статьях и на «О проекте» — это `image-slot.js` + сайдкар-файл с картинками.
- Мобильная **шторка-меню** (бургер) — на всех мобильных экранах.
- Мобильная кнопка **«Скопировать для агента»** (появляется при скролле).
- **Тёмная тема** на всех страницах (переключатель в шапке).
- **Слоты-баннеры**: если переносишь с картинками — забери сайдкар-файл состояния слотов.

## ПРАВИЛО ПРАВОК (критично, чтобы ничего не «отвалилось»)
1. Стиль меняешь в `guides-funnel-explore.html` (блок `<style>`) → пересобираешь `gf-styles.css` из этого блока. Иначе отдельные страницы не подхватят правки.
2. Логику/тексты — в `gf-app.jsx`. Обновляются все страницы сразу.
3. Все статьи и гайды пишутся как живые человеческие тексты (истории от первого лица, нумерованные уроки, вывод «Что я понял»), без смайликов.
