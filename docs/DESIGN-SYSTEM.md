# EdgeLab Space — дизайн-система портала

Единый язык визуала для blog.edgelab.space. Источник дизайна — Claude Design бандл
(`Interface and style design`, вариант C). В проде воспроизводим этот визуал в статическом HTML.

## Темы

Переключаются классом `.theme-dark` на корне (и `.gp.theme-dark` / `.phone.theme-dark` для
вложенных областей). Переключатель — солнце/луна в шапке; выбор хранится в `localStorage`.

```css
/* Светлая (по умолчанию) */
--bg:#FAF7F2; --text:#1c1c1f; --muted:#6b7280;
/* Тёмная */
.theme-dark { --bg:#141416; --text:#f4f4f5; --muted:#9ca3af; }
```

## Бренд-токены (общие для обеих тем)

```css
--ink:#0A0A0A;       /* глубокий чёрный (не #000) */
--lime:#D4FF00;      /* кислотный лайм — ОДИН акцент: CTA, маркеры, выделения */
--offwhite:#FBFBF8;  /* тёплый off-white */
```

Правило акцента: lime — точечно (квадрат-маркер, CTA, выделенное слово), всегда с ink-обводкой;
не заливать большие площади. Текст по лайму — только ink.

## Типографика

```css
--font-sans:'Inter', system-ui, sans-serif;          /* UI-текст, карточки, меню */
--font-display:'Inter Tight', system-ui, sans-serif; /* заголовки (везде, в т.ч. в теле материалов) */
--font-mono:'JetBrains Mono', ui-monospace, monospace;/* эйбрау-метки, цифры, бейджи, код */
--read-serif:'PT Serif', Georgia, serif;             /* ТЕЛО гайдов и статей — читательский лонгрид */
```
Подключение: Google Fonts (Inter 400-700, Inter Tight 400-800, JetBrains Mono 400-700, PT Serif 400/700 + italic).

**Типографика чтения («Пчела», как pchela.media).** Тело материала (гайда И статьи) —
serif-лонгрид: `--read-serif` 19px (18px на мобиле), line-height 1.72, ширина строки ~720px.
Заголовки в теле остаются `Inter Tight`, код — `JetBrains Mono`. Светлая и тёмная темы обе
настроены. Реальные классы: `.gp-content .gp-article-body` / `.m-content .gp-article-body`.

## Фирменные приёмы

- **lime-квадрат с ink-обводкой** — везде как разделитель/маркер. В эйбрау/списках — 7px outline. В ЛОГОТИПЕ — отдельный канон (ниже).
- Моноширинные цифры (JetBrains Mono) для метрик, уровней, таймкодов.
- Эйбрау-метки: моно, uppercase, с lime-квадратом.
- **Лид-цитата** — `description` материала рендерится как жирная serif-цитата с **lime-полосой слева**
  (прямой голос автора). Классы: `.gp-content .gp-desc` / `.m-content .m-desc`.
- **Блок «Похожие материалы» / «Читайте дальше»** (`.gp-related`) — внизу каждого гайда/статьи,
  карточки на токенах `.cat-card` (2 колонки на десктопе, 1 на телефоне). Драйвит рециркуляцию.
- Воздух, тонкие линии, без теней и градиентов, без emoji.

## Логотип — КАНОН (согласовано принцем 2026-06-15, не менять без OK)

Вордмарк `edgelab[■]space`: `edgelab` + lime-квадрат-разделитель + `space`. Разметка:
`<span class="el-logo"><span class="a">edgelab</span><span class="sq"></span><span class="b">space</span></span>`.

**Квадрат-разделитель (`.el-logo .sq`) — точные значения:**

```css
.el-logo .sq {
  width: 8px; height: 8px;          /* размер квадрата (box-sizing: border-box) */
  background: var(--lime);          /* заливка #D4FF00 */
  border: 1.5px solid var(--ink);   /* ink-обводка #0A0A0A (лайм внутри ≈5px) */
  box-sizing: border-box;
  display: inline-block;
  margin: 0 5px 0 2px;              /* слева 2px (вплотную к «edgelab»), справа 5px (к «space») */
  align-self: baseline; position: relative; top: 0;  /* низ квадрата НА УРОВНЕ нижней части букв (baseline), не по центру, не ниже */
}
.gp-header.dark .el-logo .sq { border-color: rgba(255,255,255,0.7); }  /* тёмная тема */
```

**Правила (зафиксированы):** размер **8×8px** (не больше — был 10px, принц забраковал «слишком огромный»); обводка **1.5px ink**; отступ слева **2px**, справа **5px**; вертикаль — **по нижней части букв** (`top:0`, baseline), НЕ по центру и не ниже. Логотип `.el-logo` — `display:inline-flex; align-items:baseline`. Применяется ВЕЗДЕ: шапка, подвал, мобильная шторка, CTA, мобильный футер.

## Компоненты (как в дизайне; в проде — статические эквиваленты)

| Компонент | Что это |
|---|---|
| `Logo` | вордмарк edgelab·space (lime-квадрат 7px). |
| `Header` + `NavLinks` | меню: Главная · Все гайды · Claude Code · Hermes · Codex · О проекте + переключатель темы + кнопка «Вступить в сообщество». |
| `PortalHead` + `MobileMenuPanel` | мобильная шапка: бургер → шторка слева. |
| `Home` | геро (баннер-слоты) + секции «Статьи» и «Гайды» (один крупный материал + список). |
| `Catalog` + `CommandPalette` | библиотека гайдов: фасеты/уровни/пагинация + поиск ⌘K (живая фильтрация). |
| `GuidePage` + `Content` | статья: TL;DR, бейдж «протестировано», блок-схема, видео, чек-лист шагов, Callout, FAQ, Changelog, тёмный CTA, сайдбар, оглавление (TOC). |
| `AboutPage` | о проекте, автор, сообщество, канал. |
| `MobileArticle` | статья в телефонной рамке; кнопка «Скопировать для агента» при скролле >1500px. |
| `Footer` | брендинг, разделы, контакты, канал, реквизиты ИП. |

## Слоты под изображения

Баннеры/обложки — заполняемые слоты (в дизайне `<image-slot>`). В текущем переносе картинки НЕ
тянем: слоты остаются как плейсхолдеры под будущий редизайн обложек и схем.

## Правило правок дизайна

Стиль — единый CSS (в дизайне собирается из `<style>` в `guides-funnel-explore.html`). В проде
правим CSS генератора (`SITE_CSS`/шаблоны), пересобираем — правка применяется ко всем страницам.
